# Обмен — локальный файлообменник офиса

Простой файлообменник внутри одной локальной сети (LAN). Один компьютер запускает сервер, остальные подключаются через браузер — ничего устанавливать не нужно.

## Группы документов

Кадры · Отпуск · Больничный · Расчёт зарплаты · НДФЛ · Другие

## Запуск

**На этом компьютере**: просто двойной клик по `start.bat` — Node.js устанавливать не нужно, launcher сам найдёт встроенный движок Kimi.

**На другом компьютере сети** (если он будет сервером): установите Node.js с [nodejs.org](https://nodejs.org), затем `start.bat`. У коллег, которые только открывают сайт в браузере, устанавливать ничего не нужно.

Ручной запуск (если Node.js установлен): `npm run dev`.

По умолчанию сервер слушает порт **7100** на всех сетевых интерфейсах.
После запуска в консоли будут показаны адреса, например:

```
на этом компьютере:  http://localhost:7100
для коллег по сети:  http://192.168.1.66:7100
```

Второй адрес отправьте коллегам — они открывают его в браузере, вводят своё имя и могут загружать и скачивать файлы. Новые файлы появляются у всех автоматически (список обновляется каждые 4 секунды).

Порт можно сменить: `npm run dev -- --port 8080`.

## Возможности

- Загрузка файлов кнопкой или перетаскиванием (до 20 файлов, до 500 МБ каждый)
- Мгновенное появление файла у всех пользователей сети
- Скачивание файла на свой компьютер одной кнопкой
- Поиск по имени файла и по имени загрузившего
- Подпись автора у каждого файла; удалить файл может только тот, кто его загрузил
- QR-код с адресом обменника (кнопка в левом нижнем углу) — коллеги подключаются с телефона за секунду
- Светлая и тёмная темы, мобильная версия
- Корректные кириллические имена файлов при загрузке и скачивании

## Где хранятся файлы

- `uploads/files/` — сами файлы
- `uploads/meta.json` — реестр (имя, группа, автор, дата)

Для полной очистки достаточно удалить содержимое папки `uploads/` при остановленном сервере.
