# Обмен — локальный файлообменник офиса

Простой файлообменник внутри одной локальной сети (LAN). Один компьютер запускает сервер, остальные подключаются через браузер — ничего устанавливать не нужно.

## Группы документов

Кадры · Отпуск · Больничный · Расчёт зарплаты · НДФЛ · Другие

## Запуск (самый простой способ)

Скачайте `Obmen.exe` из [Releases](../../releases) — это единственный нужный файл. Двойной клик — и сервер работает. Node.js, Python и любые установки **не требуются**. При первом запуске рядом появятся папка `uploads` (файлы) и `password.txt` (пароль).

## Вход по паролю

Доступ к обменнику есть только у тех, кто знает пароль:

- При первом запуске пароль **генерируется автоматически**, выводится в консоль и сохраняется в файл `password.txt` рядом с программой.
- Чтобы задать свой пароль — впишите его в `password.txt` и перезапустите сервер (или запустите с параметром `--password ваш-пароль`).
- Сообщите пароль коллегам вместе с адресом сервера.
- Пароль не хранится в коде и не попадает в репозиторий.

## Как подключаются коллеги

После запуска в консоли будут адреса, например:

```
на этом компьютере:  http://localhost:7100
для коллег по сети:  http://192.168.1.66:7100
```

Второй адрес + пароль отправьте коллегам — они открывают его в браузере, вводят пароль и своё имя, и могут загружать и скачивать файлы. Новые файлы появляются у всех автоматически (список обновляется каждые 4 секунды). Порт можно сменить: `Obmen.exe --port 8080`.

## Возможности

- Загрузка файлов кнопкой или перетаскиванием (до 500 МБ на файл, потоково — большие файлы не грузят память)
- Мгновенное появление файла у всех пользователей сети
- Скачивание файла на свой компьютер одной кнопкой
- Поиск по имени файла и по имени загрузившего
- Подпись автора у каждого файла; удалить файл может только тот, кто его загрузил
- Вход по общему паролю (cookie-сессия, защита от перебора)
- QR-код с адресом обменника (кнопка в левом нижнем углу) — коллеги подключаются с телефона за секунду
- Светлая и тёмная темы, мобильная версия
- Корректные кириллические имена файлов при загрузке и скачивании
- Лёгкий: ~30 МБ оперативной памяти, один exe весом ~8 МБ

## Альтернативные способы запуска

- **Python** (без зависимостей, Python 3.10+): `python server.py`
- **Node.js**: `npm install` один раз, затем `npm run dev` или `start.bat`

## Где хранятся файлы

- `uploads/files/` — сами файлы
- `uploads/meta.json` — реестр (имя, группа, автор, дата)
- `password.txt` — пароль доступа

Для полной очистки удалите папку `uploads/` при остановленном сервере.

## Сборка exe из исходников

```bash
pip install pyinstaller
python -m PyInstaller --noconfirm --onefile --name "Obmen" --add-data "public;public" server.py
# готовый файл: dist/Obmen.exe
```
