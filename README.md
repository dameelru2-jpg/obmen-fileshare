# Обмен — локальный файлообменник офиса

Простой файлообменник для одной локальной сети: коллеги открывают сайт в браузере,
загружают и скачивают файлы по папкам — без интернета, облаков и установки программ.

## Что нового в v2

- **Аккаунты с ником и паролем.** Регистрация — по паролю-приглашению (тот же, что в `password.txt`).
- **Файлы привязаны к владельцу.** Удалить файл может только его автор или администратор —
  выдать себя за коллегу, взяв его ник, больше нельзя (ник занят навсегда).
- **Роли.** Первый зарегистрировавшийся становится администратором: он создаёт и удаляет папки
  и может удалять любые файлы.
- **Предпросмотр.** Картинки, PDF и текстовые файлы открываются прямо в браузере.
  HTML/JS/SVG — только скачивание (защита от активного контента).
- **Поиск** по имени файла (регистронезависимый, включая кириллицу) с постраничной загрузкой.
- **«Мои файлы»** — свои загрузки с чекбоксами и массовым удалением.
- **Автоочистка**: файлы старше 7 дней удаляются автоматически (настраивается в `settings.json`).
- **Устойчивость к VPN/смене IP**: сессия живёт 30 дней и не привязана к адресу.
- **8-битный салют** при успешной загрузке 🙂

## Запуск (Windows)

1. Дважды щёлкните **`Obmen.exe`** (или `start.bat`).
2. Не закрывайте появившееся окно — пока оно открыто, обменник работает.
3. Откройте в браузере адрес из окна, например `http://192.168.2.67:7100/`.

Ничего устанавливать не нужно — exe содержит всё внутри.

### Первый вход

- Нажмите «Регистрация», придумайте ник и пароль, введите **пароль-приглашение**
  (лежит в `password.txt` рядом с exe).
- **Первый зарегистрировавшийся станет администратором.**

### Коллеги

Коллеги в той же сети открывают тот же адрес (кнопка QR в приложении покажет код
для телефона) и регистрируются по тому же паролю-приглашению.

Если сайт открывается у вас, но не у коллег — запустите один раз
`разрешить-в-брандмауэре.bat` (спросит права администратора Windows).

## Структура папки

| Файл/папка | Назначение |
|---|---|
| `Obmen.exe` | сервер-приложение, один файл |
| `password.txt` | пароль-приглашение для регистрации коллег |
| `settings.json` | настройки (`retention_days` — срок хранения файлов в днях, 0 = не удалять) |
| `uploads/` | загруженные файлы, база данных и журнал действий (`audit.log`) |
| `start.bat` | альтернативный запуск (exe → python → node) |

## Из исходников

```bash
python server.py            # нужен только Python 3.8+, без зависимостей
python server.py --port 8080 --password секрет
```

Сборка exe: `python -m PyInstaller --noconfirm --onefile --name "Obmen" --add-data "public;public" server.py`

## Безопасность

- Пароли хешируются PBKDF2-SHA256 (200 000 итераций), сессии — HttpOnly-cookie + CSRF-токен.
- Действия (входы, загрузки, удаления) пишутся в `uploads/audit.log`.
- Лимиты: вход 5 попыток/мин, регистрация 10/мин, загрузка 60 файлов/мин на пользователя.
- Ограничение размера файла — 500 МБ.

Обменник предназначен для доверенной офисной сети. Не выставляйте порт в интернет.
